# Asteroid Miner
A Space themed fast-paced and space explorable game where we use our spaceship to mine the rock, ice and rare metal containing asteroids and use the mined items to dock at our space station where we could upgrade our spaceship for more efficient mining and explore various nebulas and their stars and defend ourselves from blackholes, UFO's and meteors.

##Features
Spacecraft movement
Asteroid field
Asteroid mining and collecting resources
Undocking resources and upgrading spaceship
Collision mechanism
Exploration of Nebulae, stars and planets
Hazards like UFO and meteors
Blackhole attraction simulation

##How to Play

1. Start the game using the Play Game link.
2. Use the keyboard controls to move the spacecraft.
3. Navigate through the asteroid field.
4. Mine/collect resources.
5. Avoid dangerous collisions.
6. Try to achieve the highest score.

## Technical Implementation

Asteroid Miner is implemented as a browser-based game.

The main game logic is handled using JavaScript. The game continuously
updates the player and asteroid positions and checks for interactions
between game objects.

The implementation includes:

- Starship movement and controls
- Asteroid generation and movement
- Collision detection
- Mining/resource collection
- Undocking and upgrading of starship
- Game state management
- Game-over and restart logic

## AI Assistance
